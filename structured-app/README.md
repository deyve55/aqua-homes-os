# Aqua Homes Structured App Starter

This folder is a small structured starter shell for the Aqua Homes AI Construction OS.
It sits beside the locked v51 HTML reference and does not replace or copy it.

## Files

- `index.html` — lightweight page structure with header, approved gold bar, dashboard cards, and bottom navigation placeholder.
- `styles.css` — premium dark navy/black starter styling with the approved center-gold bar and blue/black gradient fade edges.
- `app.js` — tiny bottom navigation active-state behavior.

## Design Notes

- Keeps the first structured version intentionally small.
- Does not embed large images or base64 assets.
- Uses the v51 design truth as visual guidance without modifying the v51 HTML file.
