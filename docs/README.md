# AquaHomesOS GitHub Pages Phone-Trial Preview

This `docs` folder is a lightweight GitHub Pages preview copy of the current `structured-app` trial prototype for phone-based review.

It contains only the preview runtime files needed by GitHub Pages:

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `service-worker.js`

This folder is **not** the large AquaHomesOS v51 HTML file and should not be used as a source of truth for the main application. Do not add large images or base64 assets here.

The preview is intended to preserve the approved v51 visual direction, including the approved gold bar style, while keeping all live-risk features locked and avoiding redesign work.
